# Skills de Nexus

Skills de Claude Code del proyecto. Viven en git para que las dos PCs tengan las mismas (el resto de `.claude/` sigue fuera del repo).

| Skill | Quién la dispara | Para qué |
|---|---|---|
| `escribir-para-agentes` | el agente, al tocar una skill o los docs que carga CLAUDE.md | cómo escribir lo que lee un agente |
| `/retro` | Elías | qué cambiar en el entorno después de una sesión |
| `/cuestionario` | Elías | una decisión que no es suya, en un cuestionario para quien decide |
| `wizard` | el agente o Elías | un script en bash que lleva paso a paso por un despliegue o una configuración |
| `revisar` | el agente o Elías | la revisión de código con el batallón de agentes (el workflow `.claude/workflows/revision-nexus.js`) |

Adaptadas al español y a Nexus desde [mattpocock/skills](https://github.com/mattpocock/skills) (licencia MIT, en `LICENCIA-mattpocock.txt`).
